# Controller and Input Reference

Document controller layouts, serial protocols, polling behavior, button bit order, accessories, and platform-specific differences.

Tests should cover bit ordering, simultaneous inputs, disconnected devices, malformed recordings, and deterministic conversion between normalized input events and platform-specific records. Keep hardware facts and emulator-specific behavior separate.

Future adapters must document the source emulator/device and version. Do not claim real hardware compatibility without validation against hardware or authoritative test data.
